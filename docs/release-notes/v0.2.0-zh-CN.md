# OneZip 0.2.0

> 新增浏览压缩包的窗口、双击打开压缩包、记住密码，同名文件可以每次询问，7z 和 zip 压缩改用 7-Zip 的编码器。

[English →](https://github.com/liliwiki/OneZip/blob/main/docs/release-notes/v0.2.0-en.md)

---

## 新功能

- **浏览压缩包**：在主窗口点「打开压缩包…」，或者双击压缩包，会打开一个像 7-Zip 文件管理器的窗口。可以一层层进文件夹，双击文件用默认程序打开，解压选中的项或者全部解压，也可以把选中的项直接拖到资源管理器里。文件名加密的压缩包会先要密码
- **双击打开（文件关联）**：设置里新增「文件关联」页，可以选哪些压缩包和磁盘镜像格式双击时用 OneZip 打开，「选择常用的」一键勾上 7z、zip、rar、tar、gz 等。OneZip 会登记到 Windows 的「默认应用」里，并记住每种格式原来的打开方式，取消关联或卸载时还原。新的默认程序要由你在 Windows 里确认：页面会列出还没确认的格式，并能直接打开对应的 Windows 设置页
- **记住密码**：密码框里多了「记住这个密码」。保存的密码用 Windows 的 DPAPI 按当前用户加密，以后遇到要密码的压缩包会先自动试一遍，都不对才弹密码框。设置里新增「密码」页，可以手动添加、删除；要显示密码，得先通过 Windows Hello 或 Windows 登录密码验证。卸载时勾选删除设置，会连保存的密码一起删掉
- **同名文件每次询问**：设置 → 解压 →「遇到同名文件」多了「每次询问」。解压前如果目标位置已有同名文件，会弹一个窗口列出这些文件，选一次「都保留（新的改名）」「全部替换」或「全部跳过」

## 改进

- **7z 和 zip 压缩更快**：改用 7-Zip 的 7z.dll 压缩，和 7-Zip 是同一个编码器，多线程

## 修复

- **边下载边解压多套一层文件夹**：压缩包里只有一个顶层文件夹时，智能解压本该直接把它放进保存位置，之前却会再套一层以压缩包命名的文件夹（比如成了 `下载\pack\资料\`，而不是 `下载\资料\`）。下载前看不到压缩包里有什么，现在先解到这个新文件夹，解完发现里面只有一项，就把它挪到保存位置里。本地的 tar.zst、tar.lz4、.zst、.lz4 边解压边删除时也有同样的问题，一并修好了

## 安装

[v0.2.0 Release 页面](https://github.com/liliwiki/OneZip/releases/tag/v0.2.0)提供：

- `OneZip-0.2.0-Setup.exe`：安装程序，双击运行
- `OneZip-0.2.0-Setup.exe.sha256`：安装程序的 SHA-256

已经装了 0.1.0 的，直接运行新的安装程序，或者在 OneZip 里点“立即更新”，会装到原来的位置，设置保留。新装的话，只给当前用户安装，默认装在 `%LOCALAPPDATA%\Programs\OneZip`，不需要管理员权限；Windows 11 第一次安装时会弹一次管理员确认，把自签名证书 `CN=OneZip Dev` 加入「受信任的人」，右键菜单才能出现在第一层。

需要 Windows 10 或 11（x64）。程序没有代码签名，SmartScreen 可能会提示，点「更多信息」→「仍要运行」；运行前请核对下面的 SHA-256。

## 已知限制

- Windows 不允许程序自己把自己设成默认程序，勾选文件关联后，第一次双击这种文件时 Windows 可能会先问用哪个程序打开
- 浏览窗口里拖出文件时，会先把选中的项解到临时文件夹再拖，大文件要等一会儿
- 磁盘镜像和安装包（dmg、vhd、vhdx、msi、chm 等）只能保留原文件解压，不能边解边删
- 界面只有简体中文

## 安全提示

「边解压边删除压缩包」会在解压过程中删掉原压缩包，无法撤销，无法再找回的压缩包请先另外备份。保存的密码只有当前 Windows 用户能解密，但登录了你账户的人可以用它们解压；不想留的话可以在设置的「密码」页删除。
