# OneZip 0.2.0

> Adds an archive browser, double-click to open archives, saved passwords, and an "ask every time" choice for existing files; 7z and zip compression now use 7-Zip's encoder.

[中文版 →](https://github.com/liliwiki/OneZip/releases/tag/v0.2.0)

---

## New

- **Archive browser**: "Open archive…" in the main window, or double-clicking an archive, opens a window in the style of 7-Zip's file manager. Go through its folders, open a file with its default program, extract the selected items or everything, or drag items straight into Explorer. Archives with encrypted file names ask for the password first
- **Double-click to open (file associations)**: the new Settings → File associations page chooses which archive and disk image types open in OneZip when double-clicked; "Choose common ones" ticks 7z, zip, rar, tar, gz, and the like. OneZip registers under "Default apps" and remembers each type's previous handler, restoring it when you remove the association or uninstall. Windows asks you to confirm the new default; the page lists the types not confirmed yet and opens the matching Windows settings page
- **Saved passwords**: the password prompt has "Remember this password". Saved passwords are encrypted with Windows DPAPI for the current user and tried automatically before OneZip asks. The new Settings → Passwords page adds and deletes them; showing them requires Windows Hello or the Windows sign-in password. Uninstalling with "delete settings" ticked deletes them too
- **Ask every time for existing files**: Settings → Extract → "When a file already exists" has a new "Ask every time". If the destination already has files with the same names, one window lists them before extracting and offers "Keep both (rename the new ones)", "Replace all", or "Skip all"

## Improved

- **Faster 7z and zip compression**: compression goes through 7-Zip's 7z.dll, the same multi-threaded encoder as 7-Zip

## Fixed

- **Extracting while downloading added an extra folder**: when an archive holds a single top-level folder, smart extraction should put that folder straight into the save folder, but it was wrapped in another folder named after the archive (`Downloads\pack\data\` instead of `Downloads\data\`). OneZip can't see an archive's contents before downloading it, so it now extracts into that new folder and, when only one item came out, moves it up into the save folder. In-place extraction of local tar.zst, tar.lz4, .zst, and .lz4 archives had the same problem and is fixed too

## Installation

The [v0.2.0 release page](https://github.com/liliwiki/OneZip/releases/tag/v0.2.0) provides:

- `OneZip-0.2.0-Setup.exe`: the installer; double-click to run
- `OneZip-0.2.0-Setup.exe.sha256`: its SHA-256

If 0.1.0 is installed, run the new installer or click "Update now" in OneZip; it installs to the same folder and keeps your settings. A new installation is per user, by default to `%LOCALAPPDATA%\Programs\OneZip`, without administrator rights; the first installation on Windows 11 asks once for approval to add the self-signed certificate `CN=OneZip Dev` to "Trusted People", which the first-level context menu needs.

Requires Windows 10 or 11 (x64). The executables are not code-signed, so SmartScreen may warn; choose "More info" → "Run anyway". Verify the SHA-256 on the release page before running it.

## Known limitations

- Windows doesn't let a program make itself the default, so after you tick a file association Windows may ask which app to use the first time you double-click that type
- Dragging items out of the browser extracts them to a temporary folder first, so large files take a moment
- Disk images and installers (dmg, vhd, vhdx, msi, chm, and similar) can only be extracted while keeping the archive
- The interface is in Simplified Chinese only

## Safety

"Extract while deleting the archive" removes the archive while it extracts and cannot be undone; back up any archive you cannot replace first. Saved passwords can be decrypted only by your Windows user, but anyone signed in to your account can use them to extract; delete them on Settings → Passwords if you don't want to keep them.
