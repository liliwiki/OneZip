# OneZip 0.1.0

> Windows 一体化压缩工具的首个版本：压缩、智能解压、边解压边释放空间、边下载边解压，菜单就在 Windows 11 右键菜单的第一层。

[English →](https://github.com/liliwiki/OneZip/blob/main/docs/release-notes/v0.1.0-en.md)

---

## 概览

OneZip 把 [HatchZip](https://github.com/xevrion/hatchzip) 的"边解压边删除"和 [Peel](https://github.com/agouin/peel) 的"边下载边解压"放进同一个程序，再配上常规的压缩、解压和校验值。解压大文件时，不用先腾出一份压缩包大小的空间；中途断电、关机或者被结束，下次可以从停下的地方接着解。

右键压缩包或文件，在第一层的「OneZip」里选操作就行。每个操作只弹一个小进度窗口，做完自动关闭，不会打开主窗口。

## 主要功能

- **右键菜单**：智能解压、解压到 "名字\"、解压到当前位置、解压文件…、解压后删除压缩包、边解压边删除压缩包、测试压缩包、添加到压缩包…、添加到 "名字.7z"、添加到 "名字.zip"，以及 CRC-32、MD5、SHA-256 和全部算法的校验值。不是压缩包的文件和文件夹只显示压缩和校验值。每一项都可以在设置里隐藏，MD5 默认隐藏
- **智能解压**：压缩包里只有一个顶层文件或文件夹时直接放在旁边，否则新建同名文件夹；里面套着的压缩包会接着解开
- **解压后删除压缩包**：全部解压成功后再删除压缩包（分卷的每一卷都删），默认移到回收站；出错或取消时压缩包原样保留
- **边解压边删除压缩包**：解压过程中一批批释放原压缩包的空间，需要的额外空间远小于压缩包本身；中断后可以继续。开始前会弹出说明，确认后才开始
- **边下载边解压**：在主窗口粘贴 http(s) 链接，或者用命令行，边下载边解压，用过的下载数据立即释放，支持断点续传。所有能解的格式都支持，包括带密码的 zip、7z（含加密文件名）和 iso、cab、wim 等；磁盘镜像和安装包下载的数据要到解完才释放
- **解压格式**：zip、7z、tar、tar.gz、tar.bz2、tar.xz、tar.zst、tar.lz4、zst、lz4、分卷（.001、.z01）；rar（RAR5、RAR4，含分卷、密码和加密文件名）；借助 7-Zip 的 7z.dll 还能解 iso、udf、wim、esd、cab、arj、lzh、dmg、vhd、vhdx、vmdk、vdi、qcow2、msi、chm、cpio、rpm、deb、xar、squashfs、hfs、apfs 等。需要密码时自动弹出密码框
- **边解边删覆盖所有结构允许的格式**：除了 zip、7z、tar 系列和 rar，iso（ISO9660、Joliet、UDF）、wim/esd、cab、arj、lzh 也能边解压边释放空间。磁盘镜像和安装包（dmg、vhd、vhdx、msi、chm 等）的数据布局不允许这样做，右键菜单里就不显示这一项
- **压缩格式**：7z（LZMA2 多线程、固实、AES-256 含文件名加密）、zip（Deflate、AES-256）、tar.zst、tar.xz、tar.gz；进度按实际压缩量显示，可以随时取消，不留临时文件
- **校验值**：CRC-32、CRC-64、MD5、SHA-1、SHA-256、SHA-512，文件夹会逐个文件计算，结果一键复制
- **进度窗口**：显示已用时间、剩余时间、速度和已处理量，解压可以暂停、继续；测试结果和出错原因留在窗口里
- **保留原包解压更快**：zip、7z、rar 保留原包解压时交给 7-Zip 的 7z.dll，速度和 7-Zip 一样
- **设置窗口**：常规、解压、压缩、右键菜单、更新、关于六页，改动立即生效，可以切换浅色、深色主题
- **检查更新**：打开主窗口时自动检查（每天最多一次，可以关掉），也可以手动检查；“立即更新”会核对 SHA-256 后安装并重新打开 OneZip
- **出错记录**：任务失败和崩溃记到 `%LOCALAPPDATA%\OneZip\onezip.log`；“报告问题”会在浏览器里打开 GitHub 新问题页并填好版本和最近的出错记录
- **zip 中文密码和 7-Zip 互通**：zip 密码按系统代码页编码，和 7-Zip 一致
- **命令行**：`onezipc` 提供解压、压缩、列表、测试、校验值，和图形界面用同一套引擎
- **小文件更快**：改进了 HatchZip 在 Windows 上的落盘方式，解压 3 万个小文件从约 150 秒缩短到 26 秒

## 安装

[v0.1.0 Release 页面](https://github.com/liliwiki/OneZip/releases/tag/v0.1.0)提供：

- `OneZip-0.1.0-Setup.exe`：安装程序，双击运行
- `OneZip-0.1.0-Setup.exe.sha256`：安装程序的 SHA-256

只给当前用户安装，默认装在 `%LOCALAPPDATA%\Programs\OneZip`，可以在安装程序里换位置，安装目录里只有程序本身；不需要管理员权限，装到 `C:\Program Files` 这类受保护的文件夹时会弹一次管理员确认。Windows 11 第一次安装时会弹一次管理员确认，把签名用的自签名证书 `CN=OneZip Dev` 加入「受信任的人」，右键菜单才能出现在第一层；Windows 10 上直接写入传统右键菜单。以后升级直接运行新的安装程序，或者在 OneZip 里点“立即更新”。要卸载的话，在系统设置的「已安装的应用」里卸载，或者运行安装目录里的 `uninstall.exe`，可以选择是否同时删除设置和出错记录。

需要 Windows 10 或 11（x64）。程序没有代码签名，SmartScreen 可能会提示，点「更多信息」→「仍要运行」；运行前请核对下面的 SHA-256。

## 已知限制

- Windows 11 新式右键菜单不显示应用菜单里的第三层，所以校验值的几个算法直接平铺在 OneZip 子菜单里；「显示更多选项」的旧式菜单里是二级菜单
- 磁盘镜像和安装包（dmg、vhd、vhdx、msi、chm 等）只能保留原文件解压，不能边解边删
- 界面只有简体中文

## 安全提示

「边解压边删除压缩包」会在解压过程中删掉原压缩包，无法撤销。进度会保存在磁盘上，中断后可以继续，但无法再找回的压缩包请先另外备份。边下载边解压会释放用过的下载数据，想再解压一次就得重新下载。

报告与操作安全说明请查看 [SECURITY.md](https://github.com/liliwiki/OneZip/blob/main/SECURITY.md)。第三方内容继续遵循各自的许可条款，详情请查看 [THIRD_PARTY_NOTICES.md](https://github.com/liliwiki/OneZip/blob/main/THIRD_PARTY_NOTICES.md)。
