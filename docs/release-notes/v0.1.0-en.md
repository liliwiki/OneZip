# OneZip 0.1.0

> First release of an all-in-one archive tool for Windows: compress, extract smartly, extract in place to free space, and extract while downloading, from the first level of the Windows 11 context menu.

[中文版 →](https://github.com/liliwiki/OneZip/releases/tag/v0.1.0)

---

## Overview

OneZip brings [HatchZip](https://github.com/xevrion/hatchzip)'s in-place extraction and [Peel](https://github.com/agouin/peel)'s extract-while-downloading into one program, together with ordinary compression, extraction, and checksums. Large archives can be extracted without first freeing space for a second copy, and an extraction interrupted by a power cut, a shutdown, or a crash continues where it stopped.

Right-click an archive or a file and pick an operation under "OneZip" at the first level of the menu. Each operation opens only a small progress window that closes when the work is done; the main window stays closed.

## Highlights

- **Context menu**: smart extraction, extract to "name\", extract here, extract files…, extract, then delete the archive, extract while deleting the archive, test archive, add to archive…, add to "name.7z", add to "name.zip", and CRC-32, MD5, SHA-256, or all checksums. Files that are not archives, and folders, show only the compression and checksum items. Any item can be hidden in Settings; MD5 is hidden by default
- **Smart extraction**: a single top-level file or folder goes next to the archive, otherwise into a folder named after it; archives nested inside are unpacked too
- **Extract, then delete the archive**: deletes the archive (every volume of a split archive) only after everything extracted successfully, to the Recycle Bin by default; on an error or a cancel the archive is kept
- **Extract while deleting the archive**: frees the archive's space batch by batch while extracting, so little extra space is needed; resumes after interruption. It explains the risk and asks before it starts
- **Extract while downloading**: paste an http(s) link in the main window or use the command line; downloaded data is released as it is used, and downloads resume. Works for every format OneZip extracts, including password-protected zip and 7z (with encrypted file names) and iso, cab, wim, and the like; disk images and installers keep their downloaded data until extraction ends
- **Extraction formats**: zip, 7z, tar, tar.gz, tar.bz2, tar.xz, tar.zst, tar.lz4, zst, lz4, split archives (.001, .z01); rar (RAR5 and RAR4, including volumes, passwords, and encrypted file names); and through 7-Zip's 7z.dll, iso, udf, wim, esd, cab, arj, lzh, dmg, vhd, vhdx, vmdk, vdi, qcow2, msi, chm, cpio, rpm, deb, xar, squashfs, hfs, apfs, and more. A password prompt appears when needed
- **In-place extraction wherever the format allows it**: besides zip, 7z, the tar family, and rar, iso (ISO9660, Joliet, UDF), wim/esd, cab, arj, and lzh also free their space while extracting. Disk images and installers (dmg, vhd, vhdx, msi, chm, and similar) are laid out in a way that does not allow it, so the context menu does not offer it for them
- **Compression formats**: 7z (multi-threaded LZMA2, solid, AES-256 with encrypted file names), zip (Deflate, AES-256), tar.zst, tar.xz, tar.gz; progress follows the actual compression, and cancelling leaves no temporary files
- **Checksums**: CRC-32, CRC-64, MD5, SHA-1, SHA-256, SHA-512; folders are checked file by file, and the result can be copied in one click
- **Progress windows**: elapsed time, remaining time, speed, and amount processed; extraction can be paused and resumed; test results and errors stay in the window
- **Faster extraction when keeping the archive**: zip, 7z, and rar go through 7-Zip's 7z.dll, as fast as 7-Zip
- **Settings window**: General, Extract, Compress, Context menu, Updates, and About pages; changes apply immediately, with light and dark themes
- **Updates**: checked when the main window opens (at most once a day, can be turned off) or on demand; "Update now" checks the SHA-256, installs, and reopens OneZip
- **Error log**: failed tasks and crashes go to `%LOCALAPPDATA%\OneZip\onezip.log`; "Report a problem" opens a GitHub issue in your browser with the version and recent log entries filled in
- **Zip passwords work with 7-Zip**: non-ASCII zip passwords use the system code page, as 7-Zip does
- **Command line**: `onezipc` extracts, compresses, lists, tests, and computes checksums with the same engine as the window
- **Faster with small files**: an improvement to how HatchZip flushes files on Windows cut extracting 30,000 small files from about 150 s to 26 s

## Installation

The [v0.1.0 release page](https://github.com/liliwiki/OneZip/releases/tag/v0.1.0) provides:

- `OneZip-0.1.0-Setup.exe`: the installer; double-click to run
- `OneZip-0.1.0-Setup.exe.sha256`: its SHA-256

It installs for the current user, by default to `%LOCALAPPDATA%\Programs\OneZip`; the installer lets you choose another folder, and the install folder holds only the program itself. No administrator rights are needed unless you pick a protected folder such as `C:\Program Files`, which asks for approval once. On Windows 11 the first installation asks once for administrator approval to add the self-signed certificate `CN=OneZip Dev` to "Trusted People", which the first-level context menu needs; on Windows 10 it registers the classic context menu. To upgrade later, run the new installer or click "Update now" in OneZip. To uninstall, use "Installed apps" in Windows Settings or run `uninstall.exe` in the install folder; it asks whether to delete the settings and error log too.

Requires Windows 10 or 11 (x64). The executables are not code-signed, so SmartScreen may warn; choose "More info" → "Run anyway". Verify the SHA-256 on the release page before running it.

## Known limitations

- The Windows 11 context menu does not show a third level inside an app's submenu, so the checksum algorithms are listed directly in the OneZip submenu; the classic menu under "Show more options" groups them in a submenu
- Disk images and installers (dmg, vhd, vhdx, msi, chm, and similar) can only be extracted while keeping the archive
- The interface is in Simplified Chinese only

## Safety

"Extract while deleting the archive" removes the archive while it extracts and cannot be undone. Progress is saved on disk so an interrupted extraction can continue, but back up any archive you cannot replace first. Extracting while downloading releases downloaded data as it is used, so extracting again means downloading again.
