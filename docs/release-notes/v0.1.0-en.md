# OneZip 0.1.0

> First release of an all-in-one archive tool for Windows: compress, extract smartly, extract in place to free space, and extract while downloading, from the first level of the Windows 11 context menu.

[中文版 →](https://github.com/liliwiki/OneZip/releases/tag/v0.1.0)

---

## Overview

OneZip brings [HatchZip](https://github.com/xevrion/hatchzip)'s in-place extraction and [Peel](https://github.com/agouin/peel)'s extract-while-downloading into one program, together with ordinary compression, extraction, and checksums. Large archives can be extracted without first freeing space for a second copy, and an extraction interrupted by a power cut, a shutdown, or a crash continues where it stopped.

Right-click an archive or a file and pick an operation under "OneZip" at the first level of the menu. Each operation opens only a small progress window that closes when the work is done; the main window stays closed.

## Highlights

- **Context menu**: smart extraction, extract to "name\", extract here, extract files…, extract and delete the archive, test archive, add to archive…, add to "name.7z", add to "name.zip", and CRC-32, MD5, SHA-256, or all checksums. Files that are not archives, and folders, show only the compression and checksum items
- **Smart extraction**: a single top-level file or folder goes next to the archive, otherwise into a folder named after it; archives nested inside are unpacked too
- **Extract in place**: frees the archive's space batch by batch while extracting, so little extra space is needed; resumes after interruption
- **Extract while downloading**: paste an http(s) link in the main window or use the command line; downloaded data is released as it is used, and downloads resume
- **Extraction formats**: zip, 7z, tar, tar.gz, tar.bz2, tar.xz, tar.zst, tar.lz4, zst, lz4, rar (RAR5 and RAR4), and split archives (.001, .z01); passwords for zip and 7z, with a prompt when needed
- **Compression formats**: 7z (multi-threaded LZMA2, solid, AES-256 with encrypted file names), zip (Deflate, AES-256), tar.zst, tar.xz, tar.gz; progress follows the actual compression, and cancelling leaves no temporary files
- **Checksums**: CRC-32, CRC-64, MD5, SHA-1, SHA-256, SHA-512; folders are checked file by file, and the result can be copied in one click
- **Progress windows**: elapsed time, remaining time, speed, and amount processed; extraction can be paused and resumed; test results and errors stay in the window
- **Command line**: `onezipc` extracts, compresses, lists, tests, and computes checksums with the same engine as the window
- **Faster with small files**: an improvement to how HatchZip flushes files on Windows cut extracting 30,000 small files from about 150 s to 26 s

## Installation

The [v0.1.0 release page](https://github.com/liliwiki/OneZip/releases/tag/v0.1.0) provides:

- `OneZip-0.1.0-x64.zip`: the installation package
- `SHA256SUMS.txt`: its SHA-256

Extract `OneZip-0.1.0-x64.zip` and run in the extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

It installs for the current user to `%LOCALAPPDATA%\Programs\OneZip`. On Windows 11 it asks once for administrator approval to add the self-signed certificate `CN=OneZip Dev` to "Trusted People", which the first-level context menu needs; on Windows 10 it registers the classic context menu. To uninstall, use "Installed apps" in Windows Settings or run `uninstall.ps1`.

Requires Windows 10 or 11 (x64). The executables are not code-signed; verify the SHA-256 below before running them.

## Known limitations

- The Windows 11 context menu does not show a third level inside an app's submenu, so the checksum algorithms are listed directly in the OneZip submenu; the classic menu under "Show more options" groups them in a submenu
- Encrypted RAR archives, and formats such as iso, wim, and cab, are not supported yet
- The interface is in Simplified Chinese only

## Safety

"Extract and delete the archive" removes the archive while it extracts and cannot be undone. Progress is saved on disk so an interrupted extraction can continue, but back up any archive you cannot replace first. Extracting while downloading releases downloaded data as it is used, so extracting again means downloading again.
