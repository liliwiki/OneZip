# OneZip 0.3.0

> 新增英文界面：默认跟随 Windows 的显示语言，也可以在设置里切换。

[English →](https://github.com/liliwiki/OneZip/blob/main/docs/release-notes/v0.3.0-en.md)

---

## 新功能

- **英文界面**：主窗口、设置、各个对话框、右键菜单、文件关联里的名称、安装程序、命令行和错误提示都有了英文
- **自动跟随系统语言**：默认按 Windows 的显示语言选择界面语言。简体或繁体中文显示中文，其他语言一律显示英文
- **手动切换语言**：设置 → 常规 →「语言」可以选「跟随系统」「简体中文」或「English」，选了马上生效，不用重启

## 安装

[v0.3.0 Release 页面](https://github.com/liliwiki/OneZip/releases/tag/v0.3.0)提供：

- `OneZip-0.3.0-Setup.exe`：安装程序，双击运行
- `OneZip-0.3.0-Setup.exe.sha256`：安装程序的 SHA-256

已经装了旧版本的，直接运行新的安装程序，或者在 OneZip 里点“立即更新”，会装到原来的位置，设置保留。新装的话，只给当前用户安装，默认装在 `%LOCALAPPDATA%\Programs\OneZip`，不需要管理员权限；Windows 11 第一次安装时会弹一次管理员确认，把自签名证书 `CN=OneZip Dev` 加入「受信任的人」，右键菜单才能出现在第一层。

需要 Windows 10 或 11（x64）。程序没有代码签名，SmartScreen 可能会提示，点「更多信息」→「仍要运行」；运行前请核对下面的 SHA-256。

## 已知限制

- Windows 自己给出的错误说明（比如“系统找不到指定的文件”）按 Windows 的语言显示，不跟 OneZip 的语言设置走
- 切换语言后，已经在任务列表里的任务名和提示保持原来的语言
- Windows 不允许程序自己把自己设成默认程序，勾选文件关联后，第一次双击这种文件时 Windows 可能会先问用哪个程序打开
- 磁盘镜像和安装包（dmg、vhd、vhdx、msi、chm 等）只能保留原文件解压，不能边解边删

## 安全提示

「边解压边删除压缩包」会在解压过程中删掉原压缩包，无法撤销，无法再找回的压缩包请先另外备份。
