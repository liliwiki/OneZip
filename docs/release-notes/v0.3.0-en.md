# OneZip 0.3.0

> Adds an English interface: it follows the Windows display language by default and can be changed in Settings.

[中文版 →](https://github.com/liliwiki/OneZip/releases/tag/v0.3.0)

---

## New

- **English interface**: the main window, settings, dialogs, context menu, file association names, installer, command line, and error messages are all available in English
- **Follows the system language**: by default OneZip picks the language from the Windows display language. Simplified or Traditional Chinese shows Chinese; every other language shows English
- **Choose the language yourself**: Settings → General → "Language" offers "Follow Windows", "简体中文", or "English". The change applies at once, without a restart

## Installation

The [v0.3.0 release page](https://github.com/liliwiki/OneZip/releases/tag/v0.3.0) provides:

- `OneZip-0.3.0-Setup.exe`: the installer; double-click to run
- `OneZip-0.3.0-Setup.exe.sha256`: its SHA-256

If an older version is installed, run the new installer or click "Update now" in OneZip; it installs to the same folder and keeps your settings. A new installation is per user, by default to `%LOCALAPPDATA%\Programs\OneZip`, without administrator rights; the first installation on Windows 11 asks once for approval to add the self-signed certificate `CN=OneZip Dev` to "Trusted People", which the first-level context menu needs.

Requires Windows 10 or 11 (x64). The executables are not code-signed, so SmartScreen may warn; choose "More info" → "Run anyway". Verify the SHA-256 on the release page before running it.

## Known limitations

- Error descriptions that come from Windows itself (such as "The system cannot find the file specified") follow the Windows language, not OneZip's language setting
- After switching the language, tasks already in the task list keep their names and messages in the previous language
- Windows doesn't let a program make itself the default, so after you tick a file association Windows may ask which app to use the first time you double-click that type
- Disk images and installers (dmg, vhd, vhdx, msi, chm, and similar) can only be extracted while keeping the archive

## Safety

"Extract while deleting the archive" removes the archive while it extracts and cannot be undone; back up any archive you cannot replace first.
